# 🚗 Car Explorer & Comparison Dashboard

## 📌 Overview

The **Car Explorer & Comparison Dashboard** is an interactive Power BI project designed to explore, analyze, and compare over **1,200 cars** from multiple manufacturers.

The dashboard enables users to filter cars based on their preferences, evaluate performance through a custom scoring system, compare two cars side-by-side, and explore detailed car information using an intuitive navigation experience.

---

## 🚀 Features

- Interactive car exploration with dynamic filters
- Custom performance scoring system
- Side-by-side car comparison
- Detailed car information pages
- Category-based performance evaluation
- Interactive navigation using bookmarks and page navigation
- Responsive filtering with synchronized slicers
- Modern Car-themed dashboard design

---

## 📊 Dashboard Pages

### 🏠 Overview

Provides a high-level summary of the dataset through KPIs and interactive visualizations, including:

- Total Cars
- Total Brands
- Brands Distribution
- Fuel Type Analysis
- Price Category Overview

---

### 🔍 Explore Cars

Allows users to:

- Filter cars by multiple specifications
- Search for cars matching their preferences
- Preview detailed information for any selected car

Available filters include:

- Fuel Type
- Price Category
- Seats
- Horsepower
- Top Speed
- Acceleration

---

### 🚘 Preview Car

Displays comprehensive information about the selected car, including:

- Brand Logo
- Car Specifications
- Engine Information
- Performance Metrics
- Overall Performance Score

---

### ⚔️ Compare Cars

Allows users to compare two cars side-by-side.

Comparison includes:

- Brand
- Model
- Engine
- Price
- Overall Score

Users can also navigate to dedicated detail pages for each selected car.

---

## ⭐ Car Scoring System

A custom scoring model was developed to provide fair performance comparisons between cars.

The score is calculated using three key performance metrics:

- Horsepower
- Top Speed
- 0–100 km/h Acceleration

Each metric is normalized **within its corresponding Price Category**, ensuring that cars are evaluated against competitors in the same market segment rather than across the entire dataset.

The Overall Score is calculated using a weighted combination of three key performance metrics:

- Horsepower 40%
- Top Speed 35%
- Acceleration 25%
